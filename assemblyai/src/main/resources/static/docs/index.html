AssemblyAI Extension Documentation

Overview

The AssemblyAI extension provides advanced audio transcription capabilities with speaker diarization, sentiment analysis, and topic detection. This extension integrates with AssemblyAI's API to convert audio files into accurate, searchable text with rich metadata.

Setup

Prerequisites

  • An AssemblyAI account with an active API key
  • Audio files in supported formats (WAV, MP3, MP4, M4A, FLAC, OGG)
  • Maximum file size: 500 MB

Configuration

To configure the extension, you need to provide:

  • API Key (required): Your AssemblyAI API key
  • Base URL (optional): Custom API endpoint (defaults to https://api.assemblyai.com/v2)

Available Operations

1. Upload Audio File

Purpose: Uploads an audio file to AssemblyAI and returns a temporary upload URL.

Input:

  • Audio File - The audio file to upload

Output:

  • Upload URL - Temporary URL for the uploaded file
  • Status - Success or error status

2. Create Transcript

Purpose: Creates a transcription job for an audio file.

Input:

  • Audio URL (required) - URL from upload or external source
  • Speaker Labels (optional) - Enable speaker diarization (default: true)
  • Sentiment Analysis (optional) - Enable sentiment analysis (default: true)
  • IAB Categories (optional) - Enable topic detection (default: true)
  • Redact PII (optional) - Enable PII redaction (default: false)

Output:

  • Transcript ID - Unique identifier for the transcript
  • Status - Current status (queued, processing, completed, error)

3. Get Transcript Status

Purpose: Checks the current status of a transcription job.

Input:

  • Transcript ID (required) - The transcript identifier

Output:

  • Status - Current status (queued, processing, completed, error)
  • Message - Status description
  • Error - Error message if failed

4. Get Transcript Result

Purpose: Retrieves the complete transcription results including text, speaker information, and analysis.

Input:

  • Transcript ID (required) - The transcript identifier

Output:

  • Text - Full transcription text
  • Words - Array of words with timing and speaker information
  • Utterances - Speaker segments with text and timing
  • Sentiment Analysis Results - Sentiment for each segment
  • IAB Categories - Detected topics and categories
  • Audio Duration - Length of audio in seconds
  • Confidence - Overall transcription confidence score

Typical Workflow

  1. Upload Audio File - Upload your audio file and receive an upload URL
  2. Create Transcript - Submit the upload URL to create a transcription job
  3. Check Status - Poll the status until it shows "completed" (typically 15-30% of audio duration)
  4. Get Results - Retrieve the full transcription with all analysis data
Note: Transcription is asynchronous. After creating a transcript, you need to poll the status until it completes. Processing time is typically 15-30% of the audio duration.

Features

  • Speaker Diarization: Identifies and labels different speakers in the audio
  • Sentiment Analysis: Detects positive, negative, or neutral sentiment for each segment
  • Topic Detection: Identifies topics using IAB content taxonomy
  • PII Redaction: Optionally redacts personally identifiable information
  • Word-level Timestamps: Precise timing for each word
  • High Accuracy: Industry-leading transcription accuracy

Supported Audio Formats

  • WAV (.wav)
  • MP3 (.mp3)
  • MP4 (.mp4)
  • M4A (.m4a)
  • FLAC (.flac)
  • OGG (.ogg)

Error Handling

The extension provides detailed error messages for common issues:

  • Invalid API key
  • Unsupported file format
  • File size exceeds limit
  • Transcription errors
  • Network connectivity issues

Best Practices

  • Use high-quality audio files for best transcription accuracy
  • Enable speaker labels when multiple speakers are present
  • Poll status every 3-5 seconds to check for completion
  • Store transcript IDs for future reference
  • Handle errors gracefully and provide user feedback
